# Bella Bacio Website

This is the starter website for Bella Bacio.

## Files
- `index.html` — website content
- `style.css` — design and layout
- `script.js` — small interactive features
- `images/logo.png` — Bella Bacio logo
- `images/stay-positive-babe.jpeg` — featured product photo

## GitHub Pages
Upload all files to a GitHub repository, then go to:
Settings → Pages → Deploy from a branch → choose `main` and `/ (root)` → Save.

Before publishing, replace:
- `$00.00` with the actual product price
- `YOUR-EMAIL@example.com` with the business email
